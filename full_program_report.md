# Полный отчет по проекту «Students Monitoring» (Tulekter)

## 1. Общее описание проекта
**«Students Monitoring» (Tulekter)** — это современное веб-приложение для учета, управления и мониторинга данных о студентах и выпускниках. Программа позволяет легко добавлять, редактировать, просматривать и удалять информацию, а также экспортировать списки в форматы PDF и Excel. Система построена на базе классической клиент-серверной архитектуры с разделением на Frontend (пользовательский интерфейс) и Backend (серверная логика и база данных).

## 2. Архитектура и Технологический стек

### 2.1 Backend (Серверная часть)
Бэкенд реализован на языке **Python** с использованием современного и высокопроизводительного фреймворка **FastAPI**. 
- **База данных и ORM**: Используется **SQLAlchemy** для объектно-реляционного отображения и взаимодействия с базой данных. Подключение настраивается через переменные окружения (`.env`).
- **Аутентификация и безопасность**: Внедрена система авторизации через **JWT (JSON Web Tokens)**. Хэширование паролей осуществляется с помощью алгоритма bcrypt (`passlib`). Реализовано разделение доступа по ролям (например, `admin`, `viewer`).
- **Модули**: Структура логически разделена: `main.py` (основной файл приложения), `models.py` (структура БД), `schemas.py` (Pydantic-схемы для валидации запросов и ответов), `auth.py` (логика авторизации), `database.py` (подключение к БД).

### 2.2 Frontend (Клиентская часть)
Клиентская часть разработана на **React 19** с использованием **TypeScript** для строгой типизации и предотвращения ошибок.
- **UI-Библиотека**: Интерфейс построен на базе **Ant Design** (популярная библиотека с большим набором готовых компонентов). Используются иконки от `lucide-react` и `@ant-design/icons`.
- **Маршрутизация**: Осуществляется через `react-router-dom` (версия 7), позволяя создавать SPA (Single Page Application) без перезагрузки страниц.
- **Локализация**: Интегрирован пакет `i18next` для поддержки мультиязычности (например, Казахский / Русский / Английский).
- **Экспорт данных**: Для генерации отчетов используются библиотеки `xlsx` (экспорт в Excel) и `jspdf` вместе с `jspdf-autotable` (экспорт таблиц в PDF).
- **Взаимодействие с API**: Запросы к серверу выполняются с использованием `axios`.

## 3. Структура Базы Данных (Модели)
В системе предусмотрены 4 основные таблицы:
1. **StudentsInformation**: Главная таблица студентов/выпускников. Хранит ИИН, ФИО, категорию, статус (одобрен/на рассмотрении), место работы, должность, статус грант/платное обучение, регион, специальность и другие данные.
2. **User**: Таблица пользователей системы (администраторы, наблюдатели). Содержит email, хэш пароля, роль и ФИО.
3. **Vacancy**: Таблица вакансий для студентов. Содержит название должности, описание, компанию, зарплату, локацию и контактный email.
4. **Feedback**: Обратная связь. Хранит сообщения, имя и email отправителя, а также дату создания.

## 4. Основной функционал программы

### 4.1 Возможности интерфейса (Frontend)
- **Умный поиск (Live Search)**: Мгновенный поиск студентов по любым текстовым полям (ФИО, ИИН) без перезагрузки.
- **Фильтрация и Сортировка**: Продвинутые инструменты для выборки нужных категорий и сортировки данных по алфавиту/ID.
- **Пагинация**: Разделение большого списка на страницы для ускорения загрузки и удобства работы.
- **Управление записями (CRUD)**: 
  - 👁️ Просмотр полной карточки студента (всплывающее модальное окно).
  - ✏️ Редактирование данных в удобной форме с валидацией.
  - 🗑️ Удаление записи (с окном подтверждения для предотвращения случайных удалений).
- **Экспорт данных**: Встроенные кнопки для скачивания таблицы со всеми примененными фильтрами в форматы `.xlsx` и `.pdf`.
- **Личный кабинет**: Возможность просмотра и редактирования личного профиля.

### 4.2 Серверные возможности (API Endpoints)
Сервер предоставляет мощный REST API (автоматическая документация доступна по адресу `/docs` - Swagger UI):
- **Auth**: `/login`, `/register` — обработка аутентификации и выдача токенов.
- **Users**: `/users/me` — получение и обновление данных текущего пользователя.
- **Students**: 
  - CRUD-операции: `/students/` (GET всех с пагинацией, POST для создания, PUT для обновления, DELETE для удаления).
  - Работа с заявками: `/students/{id}/approve` и `/students/{id}/reject`.
- **Vacancies**: `/vacancies/` — получение списка вакансий (для всех) и добавление новых вакансий (только для админов).
- **Feedbacks**: `/feedbacks/` — отправка обратной связи и просмотр администратором.

## 5. Инструкция по запуску проекта

**1. Запуск Backend-части:**
```bash
cd Backend
# Создание виртуального окружения
python -m venv venv
# Активация виртуального окружения (Mac/Linux: source venv/bin/activate, Windows: venv\Scripts\activate)
pip install -r requirements.txt
# Запуск сервера
uvicorn main:app --reload
```
API будет доступно по адресу: `http://localhost:8000`

**2. Запуск Frontend-части:**
```bash
cd frontend
npm install
npm start
```
Приложение запустится в браузере по адресу: `http://localhost:3000`

## 6. Текущее состояние и перспективы развития
Проект представляет собой работоспособную систему управления данными (CRM-подобного типа) с готовой авторизацией, базой данных и полноценным UI.
**Перспективные направления для развития:**
1. Развертывание (Deploy) на боевом сервере с использованием Docker, Nginx и Gunicorn.
2. Создание отдельного интерфейса (ЛК) для самих студентов: возможность откликаться на вакансии и заполнять свой профиль.
3. Внедрение графиков и дашбордов для администраторов (статистика трудоустройства, аналитика по регионам).
4. Интеграция уведомлений (Email рассылки или Telegram-бот).
